# 服務流程與營運責任
版本：v0.1｜2026-10-03

## 1. 入口與主動接觸
合作據點邀請、自行查詢、電話、紙本及現場協助並行。
可盤點社福機構、醫院社工、學校與社區據點，但目前沒有已成立的合作。
第三人轉介只代表有接觸線索；正式建立個案及分享資料前，依適用流程確認本人同意及代理權限。
不以蒐集弱勢名單或購買個資作為主動接觸方式。

## 2. 需求盤點
先問急迫需求，再問地區、家庭概況、收入區間與已使用資源。避免初篩即索取完整身分證件。
有缺餐、居住中斷或其他急迫需要時，交給人工窗口評估即時資源，同時處理中長期申請。
詢問偏好聯絡方式與安全聯絡時間；允許不使用智慧型手機。

## 3. 初篩及行動清單
結果：可能符合／資料不足／依現有資料可能不符合。
每項結果說明來源、符合／未明／排除條件、查核日期、所需文件及承辦窗口。
資料不確定或機構規則含裁量時交人工確認。資訊不足不得自動拒絕。
排序考慮急迫性、期限、適用可能性、申請負擔與資源可用量，不只按金額。

## 4. 申請協助與授權
確認本人願意申請哪項資源，產生文件與行動清單。
協助填寫的內容由本人或合法代理人確認；是否可以代辦依方案規定及授權確認。
不預設政府有 API、可批次申請、可代簽或自動續領。
將機構要求的文件、身份驗證與送件管道逐项確認，記錄收件憑據。
敏感文件由指定私有系統管理，不透過公開 repo 流轉。

## 5. 案件狀態
候選 → 待本人確認 → 準備文件 → 已送件／已转介 → 待補件／審查中 → 核准／不核准 → 實際取得。
另設撤回、失聯、資源額滿、暫停等狀態，保留原因與可恢復的下一步。
核准與取得分開；取得證明可以是適當的本人確認或機構確認，不一律要求上傳銀行明細。
同一家庭與同一申請須去重，避免重複送件。

## 6. 追蹤與責任
每案必備：責任人、備援窗口、下一步、期限、最後接觸及下次追蹤日。
承辦回應與補件期限以正式規定為準；內部接案回應時限在試點前與據點約定。
逾期升級給備援，通知失敗改用同意的其他方式。不能把通知已發送當成使用者已收到。
結案需結果與原因；未完成案件不得因試點結束自動結案。

## 7. 更新與續辦
資源端：定期及事件觸發查核；變更須人工審核後發布，評估影響中的案件。
家庭端：本人回報失業、生育、疾病、搬家及收入變動後重新比對。
續辦提醒依各方案期限設定，提醒時間與協助容量一起評估。
資料已過期則先確認；本人退出後停止非必要追蹤，依保存政策處理資料。

## 8. 品質及異常
錯誤推薦、漏推薦、資料衝突、無效窗口及申請停滯均記錄原因與修正。
不核准案件協助理解理由、補件或可用的正式救濟管道，不保證逆轉結果。
使用者可以要求人工協助與更正資料。公開成效只使用匿名彙總，避免暴露弱勢身分。

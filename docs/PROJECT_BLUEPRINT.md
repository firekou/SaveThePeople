# 專案目標與完整藍圖
版本：v0.1｜2026-10-03｜狀態：規劃基線

## 1. 終點
使用者只需說明一次生活狀況，就能獲得候選資源、資格解釋、文件清單與申請陪伴，追蹤到實際取得幫助；之後依生活變故、政策與期限持續更新。

解決的障礙包括：不知道資源、看不懂條件、文件取得困難、找不到承辦窗口、補件失聯、錯過續領，以及不會使用數位工具。

## 2. 成果鏈
可信任據點接觸 → 本人同意 → 需求盤點 → 資源比對 → 人工確認 → 文件協助 → 送件／轉介 → 補件追蹤 → 核准 → 實際取得 → 更新／續辦。
急迫生活需求在需求盤點時直接交給人工窗口處理，不必等待完整資格問答。

## 3. 目標層次
| 層次 | 目標 | 證明 |
|---|---|---|
| 個人與家庭 | 減少漏領及申請障礙 | 原本未使用、經服務後實際取得的資源紀錄 |
| 合作機構 | 減少重複查詢、漏追及無效轉介 | 工時、接案回應及補件結果 |
| 資源提供者 | 提高資源抵達需求者的比例 | 有效轉介、受理及完成服務數 |
| 長期營運 | 成為跨機構的持續協助流程 | 重複運作、成本及續辦成果 |

## 4. 第一個試點
建議台灣一個縣市、兩個合作據點，以經濟困難且有兒少的家庭為優先；包含尚未取得低收入戶身分但近期遭逢變故者。
地區依據點合作意願、接案容量、資源供給、資料可查核程度及服務交通選擇，尚未選定城市或合作機構。

資源涵蓋生活／急難救助、兒少／就學、食物／物資、居住／就業及必要支持服務。
首輪查核 30～50 項資源，服務約 20～30 戶，目標至少 10 戶新增實際取得幫助。
未核准、仍審查、撤回與失聯都保留原因，不以送件替代取得成果。

## 5. 完整發展路徑
1. 現場驗證：確認家庭需求、合作窗口與人工服務流程。
2. 小規模服務：先以經查核資源及受訓人員協助，產生真實成果。
3. 產品化：將反覆出現的問答、規則、文件及追蹤流程系統化。
4. 持續服務：政策更新、家庭狀況更新、續領及替代資源推薦。
5. 地區複製：新地區逐項查核本地規則並建立接案網絡。
6. 跨地區擴大：依實際容量與品質擴展族群；不得直接沿用其他地區門檻。

## 6. 核心指標
- 新增實際取得幫助的家庭數：試點內去重家庭；同戶取得多項只計一戶，另統計資源項次。
- 初篩、啟動申請、送件、核准、取得各階段的家庭數與申請件數分開報告。
- 轉換率明列分母與觀察期間；審查中不得視為失敗或成功。
- 首次接觸至行動清單、送件、取得的時間。
- 每戶服務工時、每戶成功取得資源成本。
- 逾期補件、續辦完成及失聯原因。
- 以社工人工複核檢查錯誤推薦與漏推薦，不能只報推薦數。
- 非金錢資源按服務項次及內容報告，不任意換算金額。

## 7. 可持續經費
受助者免費。探索政府／基金會委託、企業公益支持及機構服務費。
以真實成本與成果提出合作方案；避免以申請量誘導無效申請，也不得讓贊助商取得個案名單。
預算須涵蓋資源維護、個案協助、系統、資安、培訓及必要交通，不只估算模型費用。
第一階段列出成本情境與經費來源，金額未核定前不宣稱已有預算。

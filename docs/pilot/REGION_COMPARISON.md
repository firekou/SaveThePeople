# 試點地區候選比較(桌面研究):新北市、臺中市、高雄市、屏東縣

> 狀態:**暫定、待訪談**。桌面研究,查核日 2026-10-18。不構成選址結論;選址為 Frank 的決策 D-04。
> 依據:`docs/PROJECT_BLUEPRINT.md` §4——依「據點合作意願、接案容量、資源供給、資料可查核程度、服務交通」選擇,對象為經濟困難且有兒少的家庭。
> 本文件不含真實個案與個人姓名;未聯繫任何機關或機構;**四縣市均不是合作夥伴**。

## 1. 摘要
- 修訂說明(2026-10-18,回應獨立審閱):「未查得」與「網路連不上」不再當作 1 分,改為**未計分/資料不足**;ranking 以「僅已計分準則」重算(§5 兩種版本)。
- 依已計分資料,新北市在多數權重下居首,屏東縣在已計分準則上墊底;**臺中市與高雄市的先後不確定**(版本 A 臺中 3.95 > 高雄 3.85,差 0.10;版本 B 高雄 4.31 > 臺中 3.38)。全為**暫定、待訪談**,非選址結論。
- 屏東縣「所有權重最後」僅在其已計分的兩項準則(資源供給、服務交通)成立——屏東「資料可查核」準則因資料不足未計分,不能據此斷言它在完整評分下必然最後(§6)。
- 屏東縣低收入戶占總戶數比率最高(2.89%),且 0–17歲人口中低收入戶占比最高(4.72%,本人計算,§3.1),具「偏鄉對照」價值。
- 「合作意願」「接案容量」無任何證據,**不計分**(§4)。

## 2. 方法
- 數字只取自實際開啟過的官方頁面/檔案;查不到者標「未查得」,不估計。

- 0–17歲人口取自 S10 單一歲資料(people_age_000 至 people_age_017,男女合計),**不是**五歲組,故可精確取 0–17;先前以 ODRP052 查詢因該 API 每頁 2,000 筆、共 460 頁而被截斷,誤判為「未查得」,已更正。

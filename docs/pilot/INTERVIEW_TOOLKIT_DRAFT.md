# 訪談工具包（草稿，待社工審閱）

版本：draft-0｜2026-10-18｜作者：Claude Sonnet 5.5｜對應 PLAN_v1 P0-3

> **狀態標記：草稿。** 未經社工審閱，未經法律審查（L-1），未經私有儲存決定（P0-8）。
> **定稿條件**：P0-7（社工督導就位）、P0-8、L-1 完成。在此之前不得用於接觸真實機構或家庭。
> **社工審閱欄**：審閱人＿＿＿＿　日期＿＿＿＿　意見＿＿＿＿（目前空白，尚無人審閱）
> 本檔不含任何真實個案、機構聯絡紀錄或合作聲明。文中「機構」「家庭」都是泛稱。

## 0. 使用原則
1. 訪談不是申請，也不承諾任何資格或結果（初篩不等於核定）。
2. 受訪者隨時可以不回答、暫停或退出，不影響其原本能得到的協助。
3. 不收集證件、證件影本、身分證字號、完整住址、帳號。需要時另以社工確認的流程處理。
4. 訪談紀錄原件放私有位置（P0-8 決定後），公開 GitHub 只放匿名彙總。
5. 訪談中出現兒童或成人安全疑慮、自傷或立即危險時，停止訪談流程，交給社工處理（對應 S-8，目前為草稿階段，流程尚未建立）。
6. 兒少相關的訪談由社工督導決定是否以及如何進行；本草稿不預設可以直接訪談未成年人。

## 1. 機構訪談大綱（約 45～60 分鐘）

目的：了解據點的實際服務流程、容量與合作條件。所有回答都標為「機構自述」，不等於書面承諾（原則 6）。

**A. 基本與服務對象**
1. 貴單位主要服務哪些對象？其中有兒少的經濟困難家庭大約占多少？（請問是估計還是統計）
2. 家庭通常如何找到貴單位？轉介來源有哪些？

**B. 目前流程與痛點**
3. 一個家庭從第一次接觸到取得協助，通常經過哪些步驟？
4. 最常卡住的地方是什麼？（找不到資源、文件、補件、聯絡不到、期限）
5. 有沒有曾經漏追、錯過期限的情形？通常原因是什麼？（不需要個案細節）
6. 現在如何記錄案件與追蹤？使用哪些工具？

**C. 資源**
7. 貴單位最常使用的資源有哪些？哪些資源的申請特別費時？
8. 有哪些資源「官方寫有、實際很難拿到」？（名額、等待時間）
9. 民間物資或名額，通常多久需要確認一次是否仍可用？

**D. 容量與合作條件（只記錄，不推進承諾）**
10. 每月大約能多接幾戶新個案？有沒有上限或旺季？
11. 急迫需求（缺糧、斷水電、居住危機）目前由誰、多久內回應？非上班時間呢？
12. 若有外部團體協助整理資源與追蹤進度，貴單位希望如何分工？不希望什麼？
13. 資料如何共享才讓貴單位放心？有什麼內部規定或上級要求？
14. 簽署層級：合作意向由誰決定？是否需要上級單位核准？

**E. 結尾**
15. 有沒有我們沒問到、但您認為重要的事？
16. 是否同意我們日後以書面方式再次確認您今天說的內容？

## 2. 家庭訪談大綱（約 30～45 分鐘，須先完成 §3 同意程序）

目的：了解尋求協助的經驗與障礙，不是需求盤點（盤點用 S-1 問卷）。

1. 當初遇到困難時，您最先想到去哪裡找幫助？
2. 找資料或申請時，哪個步驟最困難？（看不懂條件、文件、找不到窗口、交通、時間、不會用手機或網路）
3. 有沒有曾經放棄申請？原因是什麼？
4. 您比較方便用哪種方式聯絡：電話、面談、紙本、訊息？什麼時段方便？
5. 如果有人提醒期限或幫忙追蹤進度，您希望怎麼做？不希望怎麼做？
6. 您覺得什麼樣的說明方式比較容易理解？
7. 您擔心的事情有哪些？（隱私、被標籤、資料被誰看到）
8. 今天分享的內容，您希望怎麼被使用？有沒有不希望寫下來的？

禁止事項：不追問創傷細節；不要求證明文件；不評價受訪者的選擇；不暗示一定能申請成功。

## 3. 知情同意與退出流程（草稿）

### 3.1 口頭說明要點（受訪者可要求書面版）
| 項目 | 說明內容 |
|---|---|
| 用途 | 了解尋求協助的經驗，用來改善服務流程與資源整理。不是申請，不影響原有協助 |
| 資料類別 | 訪談內容（文字紀錄）。是否錄音由受訪者選擇，預設不錄音。**不收證件** |
| 分享對象 | 僅限＿＿＿＿（待 P0-8、L-1 決定名單）。對外報告只用匿名彙總 |
| 提醒 | 受訪者是否同意日後因本專案被聯絡？方式與時段由本人選擇，可選「不聯絡」 |
| 代辦 | 本訪談不含代為申請。若日後需要代辦，另行取得書面授權（待 L-1 設計授權書） |
| 撤回 | 隨時可撤回。撤回後停止使用其資料；已匿名彙總且無法辨識的部分是否可移除，由法律審查決定（待 L-1） |
| 保存期限 | ＿＿＿＿（待 P0-8、L-1 決定）。期限結束後刪除原始紀錄 |
| 費用 | 受助者免費。本專案不向受訪者收費 |
| 保密例外 | 保密有法定例外：若談話中出現兒童或少年遭受虐待、疏忽，或家庭暴力、自傷傷人等立即危險，訪談者依法或依機構規定**有通報責任**，無法完全保密。須在訪談開始前就說明這一點，並提醒受訪者可選擇不談這些內容。通報範圍、對象與時限由社工督導與法律審查（L-1）確認，此處不引用條文（待 L-1 提供） |

### 3.2 同意紀錄欄位（私有位置保存，不入公開 repo）
同意日期；說明版本；已說明項目勾選（上表九項，含保密例外）；同意的範圍（訪談／錄音／日後聯絡／匿名引用）；聯絡偏好；同意方式（口頭紀錄、簽名、其他）；說明者；若為代理同意則記錄關係與授權。

### 3.3 未成年人與法定代理人
- 草稿原則：18 歲以下受訪者須由社工督導先決定是否適合訪談；需取得法定代理人同意，並以兒少能理解的語言說明，兒少本人表示不願意時尊重其意願。
- 法定代理人與兒少意願不一致、或疑似涉及保護議題時，停止並交社工處理。
- **這些條款是設計草稿，不是法律意見。** 年齡門檻、同意權人與告知方式須由 L-1 確認。

### 3.4 退出流程
1. 受訪者以任何方式表達退出（電話、當面、透過機構）即生效，不需說明理由。
2. 接到退出後 ＿＿ 個工作天內（待定）確認已停止使用，並回覆受訪者。
3. 紀錄「退出日期、處理結果、處理人」，不記錄理由，除非受訪者願意提供。
4. 退出不影響其原有的協助與機構服務。

## 4. 匿名摘要模板（公開版可用）

只輸出彙總，不輸出可辨識資訊。

```
訪談編號：A-nn（機構）／F-nn（家庭）。編號與真實身分對照表只存私有位置
日期（月份）：
對象類型：機構層級（類型與規模區間）／家庭（僅「有兒少的經濟困難家庭」層級）
主題標籤：（例：文件困難、補件、交通、數位落差、隱私擔憂）
重點摘要（≤150 字，已去除地名、機構名、年齡、職業、家庭組成等可辨識資訊）：
受訪者自述 vs 已驗證：全部標為「自述」
後續事項：（對應工作項目 ID）
去識別檢查：第一人＿＿　第二人＿＿　（兩人皆確認不可辨識）
```

去識別規則：不寫行政區以下地名；不寫罕見組合（例如特定疾病加特定職業）；人數小於 5 的類別不單獨呈現。
